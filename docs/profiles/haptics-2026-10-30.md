# 分级触觉与可学习图例

参考 [Lookout 的多感官无障碍设计](https://design.google/library/google-lookout-design-accessibility)，核对用户不持续看屏幕时能否分辨本项目的关注与近处提醒。v0.4.26 两种风险均使用同一个 150ms 单次振动，声音关闭还会调用公共 silence，同时取消振动。

依据 [Android 触觉 API 建议](https://developer.android.com/develop/ui/views/haptics/haptics-apis)，Android 10+ 采用系统预定义 CLICK/DOUBLE_CLICK，让系统提供设备适配及平台回退；[VibrationEffect API](https://developer.android.com/reference/android/os/VibrationEffect)的有限 waveform 用于 Android 8/9 兼容。没有使用新硬件专属的强度、频率或无限重复效果，不宣称各设备振感相同。

## 行为

- 原提醒资格允许后，重新读取当前有效合并结果，选最高已确认风险。灰不请求，黄单次，红双次；未确认近处候选不能直接触发双次。
- 兼容波形为 `[0,150]` 和 `[0,100,100,150]` 毫秒，repeat=-1；现代设备优先使用预定义效果，其实际时长由平台决定。
- 控制器只记最后请求的风险。当前风险下降时取消剩余触觉，帧刷新不发出新请求；停止、检测关闭和故障清除请求。
- 音频单独停止；关闭声音、提示音失败不取消触觉。振动器缺失或拒绝请求不打断相机。系统限制和实际马达效果仍待设备记录。
- 图例紧接当前详情、位于可选增强之前，把振动语义放在第二行，完整描述包含确认及间隔。按实际最长文本行字宽选择三列/纵向，来回缩放可恢复，保持字号。

## 验证范围

七组新 JVM 回归覆盖最高风险、只在允许的请求处播放、降级/消失/clear 取消、不自动重播、两来源独立过期、未确认近处及兼容波形隔离。原生效果探针比较系统预定义和兼容效果并进行 Parcelable 往返；布局探针在原 30 种窗口/字号/主题中检查图例文本、描述与缩放恢复。实际 Activity 探针以记录输出替代马达，在真实 Camera2 活动期间使用构造深度结果，直接核对提醒选择、声音关闭独立、降级与公共停止清除；不把它当作真实 AR 或马达验收。

本地 177 项 JVM 0 失败 / 错误 / 跳过，Lint 0 错误 / 22 警告，应用及原生测试包构建通过；最终图例阅读顺序调整复核通过，云端结果完成后补记。实体振感可分辨性、TalkBack、厂商限制和真实场景仍见[待测清单](../实机测试.md)。
