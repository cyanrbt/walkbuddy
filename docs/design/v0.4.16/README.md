布局探针明确标注“取景区域（布局测试）”，只检查排版，增强测距文案来自构造数据。真实虚拟相机预览另行保存；这些证据不能代替实体设备、真实场景深度或 TalkBack 实际朗读验收。

第三轮 [41002750677](https://github.com/cyanrbt/walkbuddy/actions/runs/41002750677) 自动化全绿后，人工截图复核仍发现“未测距”在长详情末尾超出初始视口。后续将限定移到详情开头，并增加实际 AlertPolicy 文案首行与像素可见检查，避免只检查控件完整而漏掉关键含义。
