# WalkBuddy 0.4.8

ARM64 调试包，最低 Android 8；versionCode 20，包名与固定发布签名保持不变。

- 空间模式只在实时预览中可切换，避免相机已停止时继续打开增强流程。
- 不可用的主按钮使用灰暗背景，等待状态更容易区分；停止提示改为当前页面可直接理解的恢复说明。
- 页面恢复时按系统当前画中画状态校正控件，完整界面与小窗保持一致。
- Android 15/16 CI 增加虚拟后摄，真实运行 Camera2、Home 停止、手动重开、系统 PiP 采集/显示、返回完整界面、息屏恢复与小窗停止；仅通过后才能发布。保留原有帧过期与启动截止规则，不因模拟器放宽。

模拟器图像不是实体相机效果证明。真实握持视野、TalkBack 语音、系统厂商差异、耗电和实验深度阈值仍待设备验收。本应用不保存或上传画面；CI 截图仅来自模拟器测试 APK 的虚拟场景。没有提醒不代表安全，路仍要自己看。
