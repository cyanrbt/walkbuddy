# WalkBuddy v0.4.38

亮度检查改由专用线程发起 Surface 像素复制并求和，主线程接收结果；全进程最多一个未完成请求，复用 16×12 位图与像素数组。每次复制前清空，停止时取消交付，原生复制完成后再回收其缓冲，避免迟到回调污染新会话。

保留原始观测时间、暗画面阈值和每秒检查间隔；异步请求从最早到期帧起最多等待 1000ms，错误或超时停止预览，仍需手动恢复。采集/显示 1200ms、检测取样及分析截止不变。模型取样仍在原路径，不据线程迁移宣称历史停顿根因解决、实体帧率或耗电改善。

问题信息分别记录亮度等待、复制、交付阶段和结果码，保留首个事件及页面重建记录，不保存图像。[验证进展](https://github.com/cyanrbt/walkbuddy/blob/main/docs/profiles/brightness-async-2026-10-31.md)区分 JVM、模拟器、原始像素与安装包核验；当前候选尚待云端验收。实体设备、真实 AR、TalkBack 与道路体验仍待验收。
