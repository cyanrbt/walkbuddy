# WalkBuddy 0.4.15

ARM64 调试包，最低 Android 8；versionCode 27，包名与固定签名保持不变。

- 根据运行时可用处理器数选择识别 CPU 线程：不超过两个时使用单线程，更多处理器使用双线程。
- 将单/双线程的完整模型输出核对加入正常原生回归，覆盖人像、黑图、白图和重复人像，各 151 个浮点输出在 1e-6 内一致。
- 增加独立手动线程诊断：同一模拟器按 2→1→1→2 执行完整相机/模型/PiP，固定 nice 1，保留全部轮次、成功/失败和完整时序汇总。
- 正常运行只记录首帧和慢调用的时序，实验实例才记录每次推理；日志含线程数，不含画面。

[双核模拟器对照](https://github.com/cyanrbt/walkbuddy/blob/v0.4.15/docs/profiles/threads-2026-10-30.md)两套系统的八轮全部通过，单线程多数轮次的 native 中位数较低，但没有测得超时率差异，也不表示每次更快。模型权重、取样分辨率、线程优先级和各项截止不变。实体设备性能、功耗与长期稳定性待验收，间歇性分析超时继续跟踪。

本地 135 项 JVM 测试、Lint 无错误及应用/测试包构建通过；[默认配置 Android 15/16 完整回归](https://github.com/cyanrbt/walkbuddy/actions/runs/40995587065) 均成功，实际模型报告单线程，并完成原有相机、模型、布局、恢复与两轮 PiP，以及加入发布阻断的线程输出核对。
