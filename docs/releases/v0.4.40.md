# v0.4.40

预览页新增「放大取景」：点左上角四角图标收起设置，取景区域随窗口增加；再点可显示设置。停止按钮和小窗入口始终保留，检测关闭或暂停时仍显示状态，增强模式在设置收起后保留简短深度进度。

放大与恢复设置沿用当前相机和开关选择。主动进入小窗再返回后沿用本次取景选择；停止或故障时自动展开恢复说明，主动重新开启回到设置视图。首帧有效性检查及原有画面、模型截止保持。

包名 `com.cyanrbt.walkbuddy`，versionCode 52，沿用固定签名。[设计、参考与验证记录](../profiles/enlarged-viewfinder-2026-10-31.md)区分 JVM、模拟器与实体设备范围。实体设备、TalkBack、AR 与性能功耗仍待验收，不宣称修复此前自然画面过期。

开发专项保留一次后续小窗菜单第二次静音等待超时，原因尚待定位，单次复验结果另行记录。两套普通 UI 的同一检查已通过，专项复验通过也不代表该问题已修复；需调整声音时仍可展开预览操作提示音开关。
