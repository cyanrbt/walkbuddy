# WalkBuddy 0.4.22

ARM64 调试包，最低 Android 8；versionCode 34，包名 `com.cyanrbt.walkbuddy` 和固定签名保持。

- 取景标签改用系统 sp 字号，支持系统大字体；背景高度与文字基线按实际字体和字形计算，避免固定高度裁字。
- 窄画面优先完整保留「未测距」或距离，必要时收起对象名称、将「约 0.7 米」写为「约0.7米」。无法容纳整行时不绘制残缺文字，不缩小用户字号；检测轮廓和原有详情保留。
- 标签底色提高不透明度，改善明亮相机画面上的灰、黄、红文字对比度；文字与背景继续缓存，帧重绘不重复排版。
- 模型、类别、风险阈值、相机几何与时效规则保持。原生检查追加 100%/150%/200% 字号、全部 80 类、96/160/320dp、留黑边角、极小画面及亮/暗底色对比度。
- 修正模拟器唤醒后过早点击的测试就绪条件：应用有焦点后，继续等待系统输入视口活动且目标窗口可触摸，保持原真实触摸与严格失败检查。该逻辑只在测试 APK，见[失败证据](https://github.com/cyanrbt/walkbuddy/blob/v0.4.22/docs/profiles/input-target-ready-2026-10-30.md)。
