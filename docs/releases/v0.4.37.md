# WalkBuddy v0.4.37

亮度检查复用 16×12 位图与像素缓冲，批量读取替代逐像素调用。每次复制前清空，失败时不会沿用上一帧的亮度；停止相机时释放，重新观察时新建。继续读取实际显示的 TextureView，暗画面阈值和检查频率不变。

「复制问题信息」增加读回任务、任务内亮度读回的墙钟和 CPU 耗时，并记录故障发生时任务是否仍在执行。数据随首个事件冻结，页面重建后保留，开始新观察后清除，用于区分排队、读回与模型阶段；不保存图像。

采集/显示 1200ms、样本 1000ms 和分析截止保持原规则，检测、提示音和振动设置不变。此前模拟器的偶发自然停顿仍未证明根因解决，不据缓冲复用宣称实体帧率、耗电、温升或端到端延迟改善。

本地、原生逐像素/阈值/释放检查、受控位图操作计时、实际相机故障恢复及正式发布结果分别更新于[验证记录](https://github.com/cyanrbt/walkbuddy/blob/main/docs/profiles/brightness-readback-2026-10-31.md)。实体设备、真实 AR、TalkBack 与道路体验仍待验收。
