# WalkBuddy 0.4.27

ARM64 调试包，最低 Android 8；versionCode 39，包名 `com.cyanrbt.walkbuddy` 与固定签名保持。

- 确认提醒时，黄色为单次触觉，红色为双次触觉，灰色不触发。按当前有效结果的最高已确认风险选择，原连续确认与冷却间隔保持。
- Android 10+ 使用系统预定义单次/双次效果；Android 8/9 使用有限、不循环的兼容波形。实际触觉受设备与系统设置影响。
- 风险降级、目标消失、停止或检测故障会取消剩余触觉，不在刷新时自动重播。关闭声音只停提示音，触觉独立；缺少或无法使用振动器时保留视觉与相机功能。
- 图例增加触觉说明和完整无障碍描述，文字放不下时从三列切为纵向，空间恢复时复原，保持系统字号。

本地 177 项 JVM 通过，Lint 0 错误 / 22 警告，应用与测试包构建通过；最终图例排版复核通过，云端结果完成后补记，详见[触觉与图例验证](https://github.com/cyanrbt/walkbuddy/blob/main/docs/profiles/haptics-2026-10-30.md)。构造输出、系统效果构造和原生控件检查不证明实体振动、真实 AR、TalkBack 或道路效果；这些仍待设备验收。
