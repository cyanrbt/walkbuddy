# WalkBuddy 0.4.12

ARM64 调试包，最低 Android 8；versionCode 24，包名与固定签名保持不变。

- 首页顶部精简为品牌和“白天步行观察”，空间不足时收起装饰图，品牌基础字号改为 18sp 并跟随系统缩放，不使用自动缩字或省略号。
- 首次使用先显示下一步说明，再显示三步进度；尚无预览时减少重复的停止状态。
- 已完成引导后显示观察状态，摄像头权限被撤回、小窗不可用时重新展示相关步骤。设备不支持小窗时保留应用内观察说明。
- 宽窗口将品牌与状态/引导并排，减少横屏中品牌区域挤占内容。
- 原生首页检查覆盖四种窗口大小、100%/150%/200% 字体、深浅色及十种状态；检查品牌单行、文字不缩小、首次指引和实时状态的初始可见区域。

本地 135 项 JVM 测试、Lint 无错误和应用/测试 APK 构建通过。Android 15/16 云端结果待补全。相机、模型、识别调度及各项截止时间保持；此前记录的间歇性分析超时仍需继续排查，实体设备和 TalkBack 实际体验待验收。
