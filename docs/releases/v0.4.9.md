# WalkBuddy 0.4.9

ARM64 调试包，最低 Android 8；versionCode 21，包名与固定发布签名保持不变。

- 基础识别为每个识别器复用 320×320 预处理位图、像素数组、RGB 直接输入和四组直接输出缓冲区，减少持续分析时的大块分配。
- 每帧完整清理预处理画布，切换横竖画幅、透明图像时不保留上一帧的边缘；检测结果采用独立副本，后续推理不改写已经显示的内容。
- 关闭识别、停止或切换会话后仍由唯一 worker 串行关闭模型与工作区；不增加并行识别器，不改变提醒阈值及任何截止时间。
- Android 15/16 检查新增逐字节 RGB 对照、真实模型全部输出对照和有限场景的分配量观察；在实际 Camera2/PiP 中开启识别，检查分析推进、关闭重开和停止清理。

模型、类别及评分规则没有更换。分配量优化不等于设备帧率、耗电或识别准确率改善；实体后摄、TalkBack、AR 深度及 OEM 行为仍需设备验收。本应用不保存或上传画面；CI 测试人像仅在测试 APK 中，虚拟相机截图也仅由测试工具生成。没有提醒不代表安全，路仍要自己看。
