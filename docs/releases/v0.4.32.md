# WalkBuddy v0.4.32

增强测距复用每个相机实例自己的采样坐标、内参和点投影缓冲；首次取得有效深度后在后台创建，关闭时释放引用。64×96 网格的归一化采样中心只计算一次，坐标变换与相机内参仍按当前帧重新读取，网格和检测结果继续独立保存。

每个有效点使用 ARCore 写入已有数组的 Pose 接口，替代逐点创建输入/输出数组。复用前将变换和内参输出置为无效值，未写入、部分写入或无效坐标不能沿用上帧数据。阈值、采样频率、原深度时效/确认和停止保护保持。

新增六项 JVM 回归；构造的 96 组姿态、内参、稀疏更新共 589,824 个网格位置与前版分配路径逐位一致，障碍/落差的级别、距离、边界和轮廓一致，缺失变换、跨帧和相机间隔离另行验证。完整 218 项 JVM 为 0 失败 / 错误 / 跳过，Lint 0 错误 / 22 警告，应用与原生测试包构建通过；原生及发布结果见[验证记录](https://github.com/cyanrbt/walkbuddy/blob/main/docs/profiles/depth-projection-2026-10-31.md)。

这是减少指定 Java 数组创建的优化；不代表整条测距链路零分配，也没有设备流畅度、耗电、准确率或真实 AR 验收结论。基础识别、模型与标签保持。
