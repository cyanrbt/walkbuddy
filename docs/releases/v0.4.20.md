# WalkBuddy 0.4.20

ARM64 调试包，最低 Android 8；versionCode 32，保留包名 `com.cyanrbt.walkbuddy` 与固定签名。

- 开启检测时，系统小窗菜单提供「关闭检测」，无需展开完整页面即可停止检测、声音、振动和旧提醒，保留仍实时的相机画面。
- 关闭后持续显示「未检测 / 仅预览」，完整页面说明可重新勾选检测。声音保持关闭；菜单移除已无意义的关闭检测操作，仍保留结束相机的「停止」。系统只允许一个操作时优先保留停止。
- 小窗动作绑定原 Activity 与相机会话；已退休会话、其它 Activity、完整页面和重复关闭的动作均不能启动检测或相机。
- 复用 v0.4.19 的取消与资源所有权规则，原相机、分析和帧截止均保持；不增加识别类别、权限或外部服务。
