# v0.4.41

修复小窗停止命令可能作用到后来重新开启预览的问题：每次主动开启更新观察身份，系统菜单停止同时绑定当前观察和本次小窗访问。旧菜单、旧观察、旧 Activity 或无身份的停止命令不再影响当前取景。

当前小窗仍可立即停止，包括画面故障后的观察；首页和完整预览页的停止保持直接可用。停止不要求画面或检测仍实时，不延长任何画面截止。

包名 `com.cyanrbt.walkbuddy`，versionCode 53，沿用固定签名。保留 v0.4.40 的放大取景与原首帧检查，并带入后续声音命令和清理前状态诊断。[设计、参考与验证记录](../profiles/pip-stop-owner-2026-10-31.md)区分 RemoteAction 发送、原生触摸与实体范围。

实体设备、TalkBack、真实 AR、声音与性能功耗仍待验收。此前一次小窗第二次静音超时和自然画面过期仍未定位，不将本次停止归属修复视为这些问题的根因修复。
