# WalkBuddy 0.4.23

ARM64 调试包，最低 Android 8；versionCode 35，包名 `com.cyanrbt.walkbuddy` 与固定签名保持。

- 多目标取景标签在目标上、下边缘附近尝试避让，保留 2dp 间距；优先红色近障碍、黄色关注，再到灰色候选，同级优先已测较近目标及分数。不够空间时省略部分标签，轮廓、原有检测详情与提醒规则保留；展开完整预览可获得更多显示空间。
- 保持系统字号与完整测距限定，不把标签移动到远离对象的空白处。使用固定位置顺序和稳定的优先级，输入列表换序不改变标签排版；不承诺没有目标追踪时跨帧绝不跳动。
- 先绘制全部深度填充、轮廓和短连接线，最后绘制标签，避免后面的目标覆盖文字。布局仍只在新结果或几何变化时准备，重复绘制复用缓存。
- 模型、类别、分数、检测数量、风险阈值及相机/分析时效规则保持。

本地 152 项 JVM 测试、Lint 0 错误 / 22 警告、应用与原生测试包构建通过；原生与发布结果完成后补记。[排版记录](https://github.com/cyanrbt/walkbuddy/blob/v0.4.23/docs/profiles/overlay-crowd-2026-10-30.md)区分构造标签与真实识别。真实设备、OEM 字体、TalkBack 和实际密集场景对应关系仍待验收。
