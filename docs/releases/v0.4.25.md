# WalkBuddy 0.4.25

ARM64 调试包，最低 Android 8；versionCode 37，包名 `com.cyanrbt.walkbuddy` 与固定签名保持。

- 相邻结果中，同类、同风险且位置明确对应的标签优先沿用上一帧的局部边缘位置，减少小幅移动和分数互换时的上下跳换。
- 只保留位置偏好，框、文字、距离与颜色继续使用当前结果；风险优先、画面边界和 2dp 间距保持，新高风险目标仍可抢占空间。偏好不再可用时尝试其它局部位置。
- 匹配不明确、风险/测距状态/形状类型变化、超过 1000ms、时钟逆序、清除或几何改变后重新排版。没有生成目标 ID，不宣称真实物体身份追踪，也不平滑或延迟检测和提醒。
- 仍只在新结果或几何变化时排版，重复绘制复用原缓存；模型、类别、分数、确认规则与全部相机/分析截止保持。

本地 163 项 JVM 测试、Lint 0 错误 / 22 警告、应用与原生测试包构建通过。[候选 41067870083](https://github.com/cyanrbt/walkbuddy/actions/runs/41067870083) 的 Android 15/16 各九项探针首次全部成功，48 帧构造序列的垂直换位从基线各 84 次降为 0，三种重置对照通过，原字体、密集标签、风险颜色及相机/PiP 检查保留；原始附件和坐标已下载核对。
