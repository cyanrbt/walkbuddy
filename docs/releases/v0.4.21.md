# WalkBuddy 0.4.21

ARM64 调试包，最低 Android 8；versionCode 33，保留包名 `com.cyanrbt.walkbuddy` 与固定签名。

- 正在使用的完整预览页保持亮屏，减少只看画面时系统自动息屏造成的中断。
- 只对已恢复、有焦点的完整预览，在相机启动或新鲜实时画面期间保持亮屏；进入小窗前、失去焦点、暂停、停止、故障和销毁时释放。小窗遵循其它前台应用与系统的正常息屏策略。
- 使用 Activity 窗口标记，不新增唤醒锁、权限或系统亮度设置；电源键锁屏仍立即停止相机，唤醒后仍需主动重新开启。
- 原生探针设置短息屏时间并取消模拟器充电常亮，检查完整预览无触摸期间保持亮屏、小窗自动息屏后释放相机，以及唤醒后停止/手动恢复。原有模型、检测取消和小窗操作回归保留。

本地 146 项 JVM 测试通过，Lint 0 错误 / 22 警告，应用和最终原生测试包构建通过，产品表面与发布元数据检查通过。Android 15/16 原生与发布结果完成后补记。详见[亮屏生命周期记录](../profiles/screen-idle-2026-10-30.md)；OEM 多窗口、真实息屏策略与实际功耗仍待设备验收。
