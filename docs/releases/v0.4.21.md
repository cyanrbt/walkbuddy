# WalkBuddy 0.4.21

ARM64 调试包，最低 Android 8；versionCode 33，保留包名 `com.cyanrbt.walkbuddy` 与固定签名。

- 正在使用的完整预览页保持亮屏，减少只看画面时系统自动息屏造成的中断。
- 只对已恢复、有焦点的完整预览，在相机启动或新鲜实时画面期间保持亮屏；进入小窗前、失去焦点、暂停、停止、故障和销毁时释放。小窗遵循其它前台应用与系统的正常息屏策略。
- 使用 Activity 窗口标记，不新增唤醒锁、权限或系统亮度设置；电源键锁屏仍立即停止相机，唤醒后仍需主动重新开启。
- 原生探针设置短息屏时间并取消模拟器充电常亮，检查完整预览无触摸期间保持亮屏、小窗自动息屏后释放相机，以及唤醒后停止/手动恢复。原有模型、检测取消和小窗操作回归保留。

本地 146 项 JVM 测试通过，Lint 0 错误 / 22 警告，应用和最终原生测试包构建通过，产品表面、发布元数据及 12 项工具测试通过。[Android 15/16 原生检查 41043678006](https://github.com/cyanrbt/walkbuddy/actions/runs/41043678006) 两套 API 首次成功；两套附件已下载核对，各两轮实际自动息屏和完整相机/模型/PiP 回归通过。最小息屏时间为 10 秒，完整取景无输入超过 11.5 秒仍 Awake，小窗自然进入 Asleep；唤醒后仍需主动恢复。

标签发布在两套原生检查通过后生成固定签名 APK。详见[亮屏生命周期记录](https://github.com/cyanrbt/walkbuddy/blob/v0.4.21/docs/profiles/screen-idle-2026-10-30.md)；此前输入失败仍保留，未宣称其根因已全部解决。OEM 多窗口、真实息屏策略与实际功耗仍待设备验收。
