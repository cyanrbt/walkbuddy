# WalkBuddy 0.4.13

ARM64 调试包，最低 Android 8；versionCode 25，包名与固定签名保持不变。

- 停止、故障、缺少相机权限及 Activity 重建后的页面不再每 100ms 反复执行预览检查。
- 超时检查自行停止会话后不再重新排队；停止后到达的旧检查也不会重新启动轮询。
- 首页不再每 500ms 查询仅保留的已停止预览；恢复前台、重新获得焦点和点击停止时仍立即同步状态。
- 手动重新开启预览会恢复监测。系统画中画继续监测，采集、显示、模型和结果的新鲜度截止保持原值。
- 扩展真实 Activity/Camera2/PiP 探针，检查可见故障页、返回后的停止页、权限恢复、旧回调、手动重开和画中画中的实际 Handler 队列。

本地 135 项 JVM 测试、Lint 无错误和应用/测试 APK 构建通过；Android 15/16 原生检查结果待记录，发布前须通过原有完整回归及固定签名 APK 构建。移除空闲轮询不代表已测得设备耗电收益，也不表示此前间歇性识别超时已全部解决。实体设备与增强深度能力仍待验收。
