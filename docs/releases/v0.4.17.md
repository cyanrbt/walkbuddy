# WalkBuddy 0.4.17

ARM64 调试包，最低 Android 8；versionCode 29，包名与固定签名保持不变。

- 将显示方向旋转移到识别 worker，复用旋转位图后再按原顺序补边缩放；主线程只读回天然比例图像，减少横屏逐帧分配和主线程工作。
- 当前 640×480 流的每张分析采样仍为 320×240 或 240×320。90°/180°/270° 方向在 worker 首次准备 300KiB 旋转缓冲，此后容量内复用，随识别器关闭释放；主线程每帧仅分配一张 300KiB 采样。0° 不创建旋转缓冲。这减少分配频率，识别期间会保留缓冲，不代表峰值内存减半或实际帧率/耗电提升。
- 输入逐字节对照扩展至 56 组，覆盖四方向、透明像素、不同密度与连续换形；检查旋转存储复用、关闭释放和坐标回映。完整模型输出对照扩展至 16 组；保留真实 TextureView 32 组方向/画幅及完整相机/PiP 回归。
