# WalkBuddy 0.4.17

ARM64 调试包，最低 Android 8；versionCode 29，包名与固定签名保持不变。

- 摄像头读回保留天然比例，把显示方向旋转合并到识别 worker 已复用的模型输入画布，减少横屏采样的中间位图及主线程工作。
- 640×480 相机流的每张分析采样仍为 320×240 或 240×320。90°/180°/270° 显示方向省去一张同尺寸旋转位图；0° 分配不变，不从分配减少推断实际帧率或耗电收益。
- 输入像素、尺寸与检测框回映检查覆盖全部方向，真实 TextureView 32 组方向/画幅对照保留；完整模型输出对照从 4 组扩展到 16 组，包含四个方向的人像、黑图、白图与重复人像。

本地 137 项 JVM 测试、Lint 0 错误/21 警告、应用与测试包编译通过；Android 15/16 原生对照与最终发布结果待记录。实体设备性能、真实 TalkBack 与增强测距待验收，此前间歇性分析超时继续跟踪。
