# WalkBuddy 0.4.14

ARM64 调试包，最低 Android 8；versionCode 26，包名与固定签名保持不变。

- 有预览会话时将首页控制区移到顶部，减少默认右下角系统小窗遮挡“返回预览”；故障小窗仍保持顶部操作，结束会话后恢复底部布局。
- 操作区始终独立于滚动正文；圆角和无障碍遍历锚点随位置调整，保留字体缩放与正文空间。
- 增加独立小窗恢复回归：真实 Camera2 画面中注入过期，通过实际触摸从首页展开停止页、手动重新开启、再次进入小窗并检查新帧持续推进，最后触摸首页停止并检查控制区归位。
- 每套系统连续四次恢复，其中后两次先在同一 Activity 中完成锁屏、唤醒和主动重开。原有模型、几何、权限、布局和两轮完整 PiP 检查继续执行。
- 记录小窗请求、系统是否接受、模式变化及 Activity 恢复/暂停，附窗口焦点、会话状态和帧年龄；日志不含画面或身份信息。

本地 135 项 JVM 测试、Lint 无错误及应用/测试 APK 编译通过；[Android 15/16 完整原生检查](https://github.com/cyanrbt/walkbuddy/actions/runs/40992363822) 均通过，各含四次实际触摸恢复和首页停止、24 组 / 240 状态 / 240 展开布局检查及两轮完整 Camera2/模型/PiP。代表截图与调查过程见[验证记录](https://github.com/cyanrbt/walkbuddy/blob/v0.4.14/docs/验证结果.md)。

首页遮挡来自已查看的实际失败截图；此前其他快速重入异常未获得充分复现证据，不将本版表述为所有小窗问题均已修复。用户仍可将系统小窗拖到其他位置。间歇性模型分析超时仍需排查，实体设备实际触摸、系统小窗与长期稳定性待验收。
