# WalkBuddy v0.4.34

首页状态改为随预览状态、使用进度和系统小窗授权的变化更新。正常监听可用时，小窗持续播放不会让首页每 500ms 重复查询权限；同一轮刷新共用一次权限快照，连续状态通知合并到下一次主线程更新。系统无法注册授权监听时，保留可见且相机活动期间的定时回退。

预览帧和保护检查复用未变化的首页状态文字；识别启停、故障、停止和重开仍发布新状态。首页离开前台时解除观察，回来时重新读取当前权限与会话；旧页面或旧预览的迟到回调不能覆盖新会话。

相机、显示与分析的截止、故障遮挡、检测默认关闭、声音默认关闭及固定签名保持原规则。本地和云端结果、回退与真实设备边界见[验证记录](https://github.com/cyanrbt/walkbuddy/blob/main/docs/profiles/home-events-2026-10-31.md)。本版不据减少重复工作推断实际耗电、帧率或相机稳定性收益。

本地 231 项 JVM 为 0 失败 / 错误 / 跳过，Lint 0 错误 / 22 警告，应用和原生测试包构建通过。修订候选 Android 15/16 各十项全部通过，完整原始附件已下载匹配摘要；真实小窗中采集/显示继续，1100ms 首页访问查询为零，通知合并、实际授权变更与回退通过。首轮失败及测量前提修订保留，不据后续成功推断全部旧根因已解决。

正式标签构建与实际 APK 的版本、固定签名和摘要核验结果，以[验证记录](https://github.com/cyanrbt/walkbuddy/blob/main/docs/profiles/home-events-2026-10-31.md)为准；真实设备、AR 和耗电收益仍待验收。
