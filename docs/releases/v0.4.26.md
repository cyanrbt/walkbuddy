# WalkBuddy 0.4.26

ARM64 调试包，最低 Android 8；versionCode 38，包名 `com.cyanrbt.walkbuddy` 与固定签名保持。

- 修正基础识别与深度检测共用提醒间隔时，暂被拦住的提醒提前被记为已经发出的问题。
- 只有来源、目标及共同冷却均允许时才记账；新的有效结果仍满足确认条件时，在原间隔允许处发出当前提醒。不会等到下一轮目标重复周期才重新尝试。
- 不储存待发文字或距离，不增加定时提醒；目标消失、降级、过期、停止及切换后按当前状态重新判断。原连续确认、风险/距离阈值、过期、红色升级及重复提醒间隔保持。

七组新增 JVM 回归在旧实现六组失败、修正后完整 170 项测试通过；Lint 0 错误 / 22 警告，应用与原生测试包构建通过。独立纯 Java 构造轨迹中红色输出由 4900ms 恢复到 1600ms、另一来源黄色由 8700ms 恢复到 3400ms。原生检查补充两来源交替时序与实际提醒控件，覆盖 30 种字号/窗口/主题组合，云端执行与附件核验结果见[记录](https://github.com/cyanrbt/walkbuddy/blob/main/docs/profiles/feedback-cooldown-2026-10-30.md)。

构造结果只验证应用是否允许发出提醒及当前展示，不证明实际振动、声音、TalkBack 播报或实体设备反应时间；这些仍待实机验收。
