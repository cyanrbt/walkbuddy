# WalkBuddy 0.4.18

ARM64 调试包，最低 Android 8；versionCode 30，包名与固定签名保持不变。

- 为基础模型全部 80 个有效类别提供中文显示名，包括红绿灯、雨伞、手机、停车计时器等；[完整类别表](../识别类别.md)按模型原始索引列出。
- 中文表逐行保留英文键，校验 90 槽顺序、有效名称唯一性和 10 个空槽，防止漏行、错位或重复名称改变类别对应关系。
- 取景标签先显示“未测距”或估算距离，再显示对象名称。窄画面省略末尾对象文字，完整详情保留对象与位置。
- 模型权重、类别范围、原始输出、分数与风险确认规则保持；扩展全部类别的原生图层检查，涵盖 96/160/320dp 宽度和灰色、黄色、测距状态。

本地 140 项 JVM 测试、Lint 0 错误/21 警告及应用/测试包构建通过；Android 15/16 最终验证和发布结果待记录。实机识别、系统朗读及既有间歇性分析超时继续验收与跟踪。
