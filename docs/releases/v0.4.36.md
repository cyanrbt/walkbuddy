# WalkBuddy v0.4.36

预览停止后集中显示原因、恢复说明和当前可执行的操作，暂时收起不可用的检测、提示音、振动与空间增强设置。原因区域按文字高度布局，把剩余空间留给恢复说明和「复制问题信息」；重新开启后恢复设置区。

停止的小窗显示「已停止 / 请展开」，等待安装或切换时显示「请稍候 / 可展开」。两行提示随系统字号变化，完整原因与操作说明保留在无障碍描述中。展开后立即恢复完整说明，相机与提醒仍需主动重新开启。修正展开时重复渲染覆盖首页“提醒已停止”报告的问题。

基线观测在两套 Android 上各有 10/12 个小窗文字布局溢出；本轮增加完整恢复、最小小窗、展开和手动恢复的原生检查，原有检测、音频、振动、首页事件与相机保护检查保留。参考 Android 官方相机示例按运行状态呈现错误与重试操作；未引入网络权限或更换模型。

本地、云端候选、正式打包和实际 APK 的结果分别更新于[验证记录](https://github.com/cyanrbt/walkbuddy/blob/main/docs/profiles/recovery-presentation-2026-10-31.md)，[原样截图](https://github.com/cyanrbt/walkbuddy/blob/main/docs/design/v0.4.36/README.md)随验证补充。实体设备、TalkBack 实际朗读和真实道路体验仍待验收。

本地 239 项 JVM、Lint 0 错误 / 22 警告及两种 APK 构建通过。候选 API 35 首次、API 36 原源码重验后十项全部通过，完整 ZIP 已下载核对摘要，首轮自然帧龄 1246ms 的过期失败保留，不称其根因已修复。正式标签继续独立检查全部门槛与固定签名，实际下载结果见验证记录。
