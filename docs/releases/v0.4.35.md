# WalkBuddy v0.4.35

检测运行时，系统小窗菜单增加「打开提示音 / 关闭提示音」，可以直接调整提示音，保留实时画面、检测和振动选择。动作名称和图标随当前选择更新；完整预览页的「声音」改称「提示音」，明确其控制范围，系统朗读仍独立设置。

菜单优先保留「停止」相机和「关闭检测」，系统提供至少三个自定义位置时显示声音动作。旧声音选择、旧小窗轮次、旧预览及缺失参数的命令会被拒绝；展开后的旧按钮也不能改变完整页选择。声音设备失败时关闭提示音并更新菜单，画面和检测继续。

横屏设置侧栏按开关完整文字所需宽度扩展，避免大字体下「提示音」被挤成两行；保留原字号及至少 40% 的横屏取景宽度。

新增六项菜单容量与状态策略 JVM 回归，以及实际系统菜单触摸、旧 PendingIntent、连续画面/模型和受控音频失败检查。原模型、保护截止、相机默认行为与固定签名保持。完整本地、模拟器、发布与设备范围见[验证记录](https://github.com/cyanrbt/walkbuddy/blob/main/docs/profiles/pip-sound-controls-2026-10-31.md)。
