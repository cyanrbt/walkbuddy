# WalkBuddy 0.4.19

ARM64 调试包，最低 Android 8；versionCode 31，包名 `com.cyanrbt.walkbuddy` 与固定签名保持。

- 模型准备或推理失败、分析超过原有截止时，关闭检测、声音、振动和旧反馈；采集与显示仍实时的情况下继续保留画面，支持以小窗观察。
