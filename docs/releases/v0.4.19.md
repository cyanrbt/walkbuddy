# WalkBuddy 0.4.19

ARM64 调试包，最低 Android 8；versionCode 31，包名 `com.cyanrbt.walkbuddy` 与固定签名保持。

- 模型准备或推理失败、分析超过原有截止时，关闭检测、声音、振动和旧反馈；采集与显示仍实时的情况下继续保留画面，支持以小窗观察。
- 完整预览显示“仅预览”和故障说明，小窗持续显示“未检测 / 仅预览”。用户展开后可重新勾选检测，声音保持关闭，不自动重启检测。
- 采集或显示过期、相机故障、锁屏和离屏仍完整停止相机；分析取消仍由原唯一 worker 持有活动帧直到 native 返回，旧结果不会恢复提醒。
- 增加原生模型加载失败和阻塞分析注入，检查相机/纹理保留、旧反馈清除、小窗警示、迟到结果丢弃及重新开启实际模型。布局覆盖大字体和 96×128 小窗警示。

本地 146 项 JVM 测试通过，Lint 0 错误/22 警告及应用/测试包构建通过。详细行为、时效与验证范围见[检测降级记录](../profiles/detection-fallback-2026-10-30.md)。Android 15/16 云端验证和发布附件核验在完成后补记。

模型、识别类别和风险阈值未增加。此版本改善检测故障后的可用性，不表示模型更快、原始超时根因已修复或新增台阶识别。真实设备、AR 深度和系统朗读继续验收。
