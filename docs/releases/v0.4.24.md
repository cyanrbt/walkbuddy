# WalkBuddy 0.4.24

ARM64 调试包，最低 Android 8；versionCode 36，包名 `com.cyanrbt.walkbuddy` 与固定签名保持。

- 重叠填充、轮廓和短连接线按灰→黄→红绘制，红色近障碍边线最后呈现，避免较低风险轮廓因检测列表换序盖住它。文字仍在全部形状之后绘制，保留系统字号、标签避让和完整限定。
- 绘制顺序只随新结果或几何变化准备并缓存；保留原检测列表及同风险内顺序，重复重绘不排序，清除或几何失效时释放绘制缓存。
- 模型、类别、分数、检测数量、提醒、风险阈值与时效不变。本版改善视觉层级，不实现跨帧标签追踪，也不改变真实深度识别能力。

本地 152 项 JVM 测试、Lint 0 错误 / 22 警告、应用与原生测试包构建通过。[修正候选 41059784053](https://github.com/cyanrbt/walkbuddy/actions/runs/41059784053) 的 Android 15/16 各九项探针首次全部成功，14 组风险颜色全匹配；独立解码 PNG 核对采样值和顺序图像一致，原字体、密集标签、蒙版层级及相机/PiP 检查保留。

详见[绘制层级记录](https://github.com/cyanrbt/walkbuddy/blob/v0.4.24/docs/profiles/risk-paint-2026-10-30.md)与[前后截图](https://github.com/cyanrbt/walkbuddy/blob/v0.4.24/docs/design/v0.4.24/README.md)。实体设备、真实重叠目标、OEM 字体与 TalkBack 仍待验收，发布附件核验另见[验证结果](https://github.com/cyanrbt/walkbuddy/blob/main/docs/验证结果.md)。
