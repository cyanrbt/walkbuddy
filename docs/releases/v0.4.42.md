沿用一个复制入口，已有首次问题时显示「复制问题信息」，保留冻结的首因；当前快照不保存为故障，不随页面状态恢复。复制不停止相机、模型或改变开关，不包含画面，也不自动发送。检测暂停但画面继续时，仍优先复制已记录的问题。

包名 `com.cyanrbt.walkbuddy`，versionCode 54，沿用固定签名。保留放大取景、停止归属和原首帧/画面保护。[参考、设计与验证记录](../profiles/observation-copy-2026-10-31.md)区分纯预览、实际模型、受控故障与保存回调。

[正式发布流程](https://github.com/cyanrbt/walkbuddy/actions/runs/41206744467)的两套 UI 与 APK 三作业均首次成功，实际 APK 已完整下载核对版本、原固定签名、ARM64、模型和服务端摘要；[构建记录](../profiles/observation-copy-release-2026-10-31.json)与[APK 记录](../profiles/apk-v0.4.42.json)保留。正式 UI ZIP 未本地重复重放。
