# WalkBuddy 0.4.7

ARM64 调试包，最低 Android 8；versionCode 19。包名与固定发布签名保持不变。

- 实时检测详情与“最近提醒”分开：详情持续更新；最近提醒使用独立、可见的礼貌 live region，移除手动无障碍 announcement，减少距离变化引起的重复朗读。相同内容不重复更新；声音开关只控制提示音，系统朗读单独设置。
- 修复黄到红的风险升级被旧冷却丢弃；受限提醒保留到适当时机，并使用当前内容。目标消失、降级、关闭检测、画面变换和停止会撤销旧提醒。
- 故障页按原因说明下一步：权限缺失前往摄像头设置，过暗/占用提示检查镜头及系统开关，增强或模型失败可主动回到基础预览，不支持的相机配置返回首页。
- 安装或切换等待时禁止重复恢复；切回基础模式会等待增强相机释放。恢复后检测和声音默认关闭，从设置返回或 Activity 重建不会自动打开摄像头。

本地 110 项 JVM 测试、Lint 与 APK/仪器测试 APK 编译通过。发布检查扩展到 Android 15/16：每个系统运行 16 组布局、352 组故障提示展示、提醒语义/过期行为、轮廓像素检查，以及真实 Activity 的缺权限→设置意图→授权→重建流程；流程探针不打开相机。

这些检查不等于真实 TalkBack 的声音和打断策略验收，也不证明实体相机、系统 PiP、耗电或空间检测效果。空间/落差检测仍是实验能力，阈值未完成真机标定。没有提醒不代表安全，缺失深度不代表可通行，路仍要自己看。应用不保存或上传画面，安装包没有网络权限。
