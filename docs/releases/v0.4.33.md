# WalkBuddy v0.4.33

默认关闭检测时，完整取景页的状态改为「仅预览」；首次进入系统小窗就显示「未检测 / 仅预览」，避免把实时相机画面当作检测和提醒正在工作。普通完整页继续由检测开关及详情说明状态，不额外堆叠同一条提示。

检测开启后撤下仅预览提示；检测故障或小窗菜单手动关闭检测后的原有提示仍保留。停止、过期和离屏时仍遮挡并停止相机，提示不将已失效画面标成实时预览。小窗内仅预览提示优先于可选深度进度及姿势文字。

本版不自动开启检测或声音，不改变模型、风险、提醒和截止。新增六项 JVM 状态回归，以及默认页/小窗/重开、检测启停和 30 组窗口/字号的原生检查；最终结果及截图见[验证记录](https://github.com/cyanrbt/walkbuddy/blob/main/docs/profiles/preview-only-default-2026-10-31.md)。真实设备、TalkBack 朗读及 AR 效果仍待验收。

本地完整 224 项 JVM 为 0 失败 / 错误 / 跳过；Lint 0 错误 / 22 警告，应用和原生测试包构建通过。云端与实际 APK 结果见上方验证记录。
