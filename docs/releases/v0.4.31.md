# WalkBuddy v0.4.31

提示音的创建、播放、停止与释放移到独立串行线程；声音开启时准备并复用一个音频输出，减少反复创建。初始化失败或播放请求被系统拒绝时关闭声音开关并提示「提示音暂不可用，画面与检测继续」，检测、画面与独立振动选择继续工作。

最多保留一个最新待播放请求，实际播放前重新核对原相机/检测会话和结果有效期。声音关闭、停止、模式/几何变化时取消本音频会话；风险降低或消失时取消旧请求，不因风险恢复自动补播。基础结果的 1000ms、深度结果的 500ms 有效期及原确认/提醒频率保持。

已进入系统音频调用的操作不能强制中断；取消入口不等待该调用，返回后再停止并释放。单次提示仍为原来的 150ms。没有对实际播放延迟、流畅度或耗电作出测量结论，也不将本版称为历史小窗显示停顿的根因修复。

## 验证

新增 12 项音频线程/取消回归及 2 项结果有效期回归，完整 212 项 JVM 为 0 失败 / 错误 / 跳过；Lint 0 错误 / 22 警告，应用及原生测试包构建通过。Android 15/16 原生检查、正式发布与下载附件仍待确认；具体结果将记录到[验证文档](https://github.com/cyanrbt/walkbuddy/blob/main/docs/profiles/tone-threading-2026-10-31.md)。实体设备声音、蓝牙/勿扰/厂商策略、TalkBack 与真实 AR 仍待验收。
