# Walk Buddy

把后置摄像头留在系统画中画里，切到别的应用后继续看实时画面。无需“在其他应用上层显示”权限；设备不支持或关闭画中画时，可以使用应用内预览。

这是一个 Android 学习原型，当前版本 **0.3.0**。可选的本地识别只是说「画面里可能有人、车或路边的椅子」，不能替你判断前面能不能走。

## 打开之后

1. 允许摄像头，点「打开摄像头预览」。不需要悬浮窗或通知授权。
2. 先站着确认镜头方向，再点「以小窗观察」。窗口拖动、缩放和返回完整界面由系统管理，具体交互随系统版本变化。
3. 点击小窗菜单的「停止」或系统关闭按钮结束观察；完整预览页和首页也能停止。

- 辅助识别和声音在完整预览页设置，每次开启默认关闭。声音只在识别开启后可用。
- 锁屏、关闭小窗或预览完全离开屏幕时，释放摄像头并停止提醒。回到预览页后需主动重新开启。
- 不自动进入画中画；直接按 Home 离开完整预览会停止相机。请先点「以小窗观察」。
- 首页可查看画中画支持情况并打开系统设置。小窗被禁用或进入失败时，保留应用内画面并提供设置入口，不回退到特殊悬浮窗。

识别在手机上完成，只看这八类：人、自行车、汽车、摩托车、公交车、卡车、椅子、长凳。连续两次看到同一类，才会短震一下。它不量距离，也不管台阶、坑洞和玻璃。没有提醒，只说明这次没有出声。

画面不保存，也不上传。安装包没有网络权限。

## 适合的场合

白天、平路、你本来就会看周围的时候，拿来多留一个画面。先站着确认镜头对着你想看的方向。自然拿着手机时，后置镜头经常朝向地面。

不要在马路、楼梯或骑行时靠它决定下一步。

## 下载

推送 `v` 开头的标签后，GitHub Actions 会构建 arm64 调试包并挂到 [Releases](https://github.com/cyanrbt/walkbuddy/releases)。当前版本的文件名是 `Walk-Buddy-v0.3.0-arm64-debug.apk`，只含 arm64-v8a，最低 Android 8。

装好后允许摄像头并打开预览，确认取景后点「以小窗观察」。系统若拒绝覆盖安装，先卸载旧包：调试签名变了就不能直接升级。

想让以后每次发布都用同一把调试签名，把用密码 `android`、别名 `androiddebugkey` 生成的密钥库做一次 base64，存成仓库密钥 `DEBUG_KEYSTORE_BASE64`。没有这把密钥时，Actions 会把第一次生成的调试密钥库放进构建缓存。

## 构建

需要 JDK 17，以及 Android SDK 36（platforms、build-tools 36.0.0、platform-tools）。在项目根写下 `local.properties`：

```
sdk.dir=/绝对路径/android-sdk
```

```sh
python3 scripts/check_model.py
./gradlew assembleDebug testDebugUnitTest lintDebug
```

调试包在 `app/build/outputs/apk/debug/app-debug.apk`。默认只有 arm64-v8a，最低 Android 8。四 ABI 包用 `./gradlew assembleDebug -PuniversalApk`。

固定组合是 Java 17、Gradle 8.13、Android Gradle Plugin 8.10.1、LiteRT 1.4.0。第一次构建会下载依赖。应用运行时不联网。
